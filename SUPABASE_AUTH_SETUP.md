# Gmail OTP + Google Login setup

The `sdk57` branch now uses Supabase Auth for:

- 6-digit email OTP login sent to Gmail addresses.
- Google/Gmail account OAuth login with `Continue with Google`.

## 1. Install dependencies

Run in the project root:

```bash
npm install
```

## 2. Configure Supabase

Create a Supabase project and copy the project URL and anon/publishable key.

Create a local `.env` file from `.env.example`:

```env
EXPO_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Never put a Supabase service-role key in the mobile app.

## 3. Enable email OTP

In Supabase Dashboard:

1. Open Authentication > Providers > Email.
2. Enable Email provider.
3. Keep email/password sign-in optional; this app uses `signInWithOtp`.
4. Configure the email provider/SMTP if you want reliable production delivery and a custom sender.

The app calls `signInWithOtp`, then `verifyOtp` with the 6-digit code.

## 4. Enable Google login

In Supabase Dashboard:

1. Open Authentication > Providers > Google and enable it.
2. Create a Google OAuth client in Google Cloud Console.
3. Add the Supabase callback URL shown by Supabase to the Google OAuth client's authorized redirect URIs.
4. Enter the Google client ID and client secret in Supabase.

## 5. Add the Expo redirect URL

The app uses the Expo scheme `mjya` and redirects to:

```text
mjya://auth/callback
```

Add that URL to Supabase Authentication > URL Configuration > Redirect URLs.

For Expo Go development, the redirect URL can be different depending on the development environment. If Google login does not return to the app, use the redirect URI generated by `expo-linking` for your development build and add that exact URI to Supabase.

## 6. Start the SDK 57 app

```bash
npx expo start -c
```

Then test:

1. Enter a Gmail address.
2. Tap **Send Gmail OTP**.
3. Enter the 6-digit code received by email.
4. Or tap **Continue with Google** to sign in with a Google account.

The authentication session is persisted with AsyncStorage.
